How the status is decided

Only constraints on packages that follow Sylius numbering count (sylius/sylius and its sub-packages). A plugin is ready when a stable release published after Sylius 2.0.0 accepts at least one Sylius 2 version and names Sylius 2 explicitly: an open-ended >=1.9 does not count. "Active" means a stable release since 1 January 2024 and not marked abandoned. Replacements and deprecations come from the authors' own README. Full method and dataset: study on Zenodo.

Check your whole project

A shop can only upgrade once every plugin is ready. Sylius Upgrade Analyzer (open source, MIT) checks each plugin in your composer.json along with the rest of the breaking changes, whatever PHP version your project runs:

docker run --rm -v "$PWD:/project" ghcr.io/pierrearthurdemengel/sylius-upgrade-analyzer
