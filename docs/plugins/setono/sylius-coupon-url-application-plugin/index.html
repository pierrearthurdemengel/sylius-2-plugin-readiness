Only as a pre-release. setono/sylius-coupon-url-application-plugin v3.0.0-alpha (18 May 2026) accepts Sylius 2 with sylius/core ^2.0, sylius/core-bundle ^2.0, sylius/order ^2.0, sylius/promotion ^2.0, but no stable release does yet.

What to do

You can test the pre-release on a branch, but avoid shipping it to production without pinning the exact version and reading its changelog. Watch the repository for the first stable tag.
